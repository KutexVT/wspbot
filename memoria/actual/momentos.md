# MOMENTOS — lo que peso emocionalmente

No es un diario. Aqui solo entra lo que **cambia como hay que tratarla despues**:
una pelea, un bajon, algo que le dolio, algo que le hizo mucha ilusion.

Se consulta cuando ella se pone sensible, nostalgica, o referencia algo del pasado
con carga. La mayoria de los dias este archivo no se abre, y esta bien.

- **Cuidado:** el se quedo con la idea de "dejar de hacer sorpresas" y ella le dijo que no hace

## Como se mantiene
- Una entrada solo si de verdad cambia algo hacia adelante. Si no deja lectura, no entra.
- Cada entrada lleva **fecha + que paso + que aprendi para la proxima**.
- Nunca se borra ni se reescribe una entrada vieja. Si algo cambio, se agrega entrada nueva.
- Si algo aqui contradice `ginger_novia.md`, NO lo resuelvo solo: lo marco
  "(revisar — contradice ginger_novia.md)" y que lo vea Mikel.
