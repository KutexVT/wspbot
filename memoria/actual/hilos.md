# HILOS — conversaciones abiertas

Para saber por donde retomar cuando hay silencio, o para no llegar en frio si ella
menciona algo que ya veniamos hablando.

Un hilo se abre cuando el tema aparece mas de una vez. Se cierra cuando se resolvio
o cuando lleva ~2 semanas sin tocarse (baja a CERRADOS, no se borra).
